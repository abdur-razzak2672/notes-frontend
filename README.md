# Notes Client

Minimal React (Vite) frontend for the Notes API.

```bash
cp .env.example .env    # set VITE_API_URL to the backend /api url
npm install
npm run dev
```

Features: login/register, my notes CRUD, posts feed and per-user posts, profile with interests.
Admin also gets: user management, everyone's notes, users grouped by interest.
